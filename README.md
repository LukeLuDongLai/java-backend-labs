# Java Backend Labs

A project-based Java backend learning repository.


## Current Milestone

M1 - EventFlow Core

An in-memory event ticket booking system built with Java 21.

## Tech Stack

* Java 21
* Maven
* JUnit 5

## Current Goals

* Model events and bookings
* Implement ticket pricing rules
* Practice object-oriented design
* Prevent ticket overselling
* Practice testing and Git workflow

## Build

```bash
mvn clean verify
```
